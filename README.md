# Python Voice Assistant 🎙️

A Python-based voice assistant that can understand voice commands and perform different tasks such as opening applications, searching the web, checking Wikipedia, controlling system volume, and more.

## 🚀 Features

* 🎤 Voice command recognition
* 🔊 Text-to-Speech using Microsoft Zira voice
* 🌐 Open Google
* 📺 Open YouTube
* 🔎 Google search using voice
* 🔎 YouTube search using voice
* 🎵 Search music on YouTube
* 📚 Wikipedia search
* 🕐 Tell current time
* 📅 Tell current date
* 💻 Open Visual Studio Code
* 🌐 Open Chrome
* 📧 Open Gmail
* 📝 Open Notepad
* 🧮 Open Calculator
* 📁 Open File Explorer
* 🔊 Increase volume
* 🔉 Decrease volume
* 🔇 Mute and unmute system volume
* 👋 Voice greetings
* 🚪 Exit using voice command

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* PyAudio
* pycaw
* comtypes
* Wikipedia API

## ▶️ How to Run

1. Install Python.

2. Install the required packages:

```bash
pip install SpeechRecognition pyttsx3 PyAudio pycaw comtypes wikipedia
```

3. Open the project folder in VS Code.

4. Run:

```bash
python listener.py
```

5. Speak a command when the assistant starts listening.
